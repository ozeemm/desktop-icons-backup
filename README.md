# Desktop Icons Backup

Консольное приложение для сохранения и восстановления расположения значков на рабочем столе Windows. Приложение запоминает координаты значков в отдельных именованных профилях.

## Требования

- Windows 10 или новее.
- .NET 10 Runtime для запуска собранного приложения.
- Для сборки из исходного кода — .NET 10 SDK.
- Папка приложения должна быть доступна для записи: профили хранятся рядом с исполняемым файлом.

## Запуск

Запустите `DesktopIconsBackup.exe` без аргументов, чтобы открыть интерактивное меню:

1. **Сохранить текущее расположение** — введите имя профиля. Если профиль с таким именем уже существует, приложение спросит подтверждение перезаписи.
2. **Восстановить сохраненное расположение** — выберите профиль из списка.
3. **Показать сохраненные профили** — вывести список профилей.
0. **Выход**.

Также приложение можно запускать из терминала с командами:

```powershell
.\DesktopIconsBackup.exe save "Рабочий стол"
.\DesktopIconsBackup.exe restore "Рабочий стол"
.\DesktopIconsBackup.exe list
.\DesktopIconsBackup.exe --help
```

Вместо `.exe` можно использовать `dotnet run --` из папки проекта:

```powershell
dotnet run -- save "Рабочий стол"
dotnet run -- restore "Рабочий стол"
dotnet run -- list
```

Команда сохранения из терминала перезаписывает существующий профиль с тем же именем без дополнительного подтверждения. Имена профилей не должны содержать символы, запрещенные в имени файла Windows, или разделители пути.

## Где хранятся профили

Каждый профиль — отдельный JSON-файл в папке `Layouts` рядом с приложением:

```text
DesktopIconsBackup.exe
Layouts/
  Рабочий стол.json
  Работа.json
```

Профиль содержит имена значков и их координаты. Не удаляйте и не редактируйте JSON-файлы вручную, если не уверены в их формате.

## Восстановление при изменившемся наборе значков

При восстановлении приложение сопоставляет значки по имени:

- Для найденных в профиле значков применяются сохраненные координаты.
- Сохраненные значки, которых сейчас нет на рабочем столе, перечисляются в отчете.
- Новые значки, отсутствующие в профиле, остаются на текущих местах и тоже перечисляются.

## Сборка из исходного кода

В папке проекта выполните:

```powershell
dotnet build
```

Приложение использует Win32 API для чтения и применения координат в списке значков Windows Explorer, поэтому операции сохранения и восстановления доступны только в Windows.
